# Prácticas Profesionales — Intermoda
**Stephany Sofia Alanis Mendez**

Bitácora PWA de horas de prácticas profesionales.

## Estructura
```
intermoda-pwa/
├── public/
│   ├── index.html       ← App principal
│   ├── manifest.json    ← Config PWA
│   ├── sw.js            ← Service Worker (offline)
│   └── icons/
│       ├── icon-192.png
│       └── icon-512.png
└── vercel.json          ← Config Vercel
```

## Deploy en Vercel
1. Sube esta carpeta a un repo de GitHub
2. Entra a vercel.com → New Project → importa el repo
3. En "Root Directory" pon `public`
4. Deploy

## Instalar en iPad (Safari)
1. Abre la URL de Vercel en Safari
2. Toca ⬆️ Compartir
3. "Agregar a pantalla de inicio"
4. ¡Listo!
